# PrixMarché

Application web de collecte et de consultation des prix sur les marchés, développée avec **Django**.

Projet réalisé dans le cadre du cours de **Développement Web sous Python** – ISSEA AS3 (2026-2027).

---

## Fonctionnalités

- Gestion des **Marchés**
- Gestion des **Produits**
- Gestion des **Enquêteurs**
- Gestion des **Affectations** (enquêteur ↔ marché)
- Gestion des **Relevés de prix**
- Interface d’administration Django
- Interface web simple et claire

---

## Technologies utilisées

- Python 3
- Django 5.2
- SQLite (développement)
